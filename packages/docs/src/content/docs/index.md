---
title: Geospatial for Directus
description: Spatial operations for Directus, in the database, the API, the SDK and the Studio.
---

Geospatial answers spatial questions about the items of a Directus project, such as which items lie within a distance
of a point, with the permissions of whoever asks: a user only ever receives the items `/items` would give them.

The extension is in development, and these docs grow with it.

- [Radius](/guides/radius/): the items within a distance of a point, through the API and the SDK.
- [API reference](/api/): every route of the extension, generated from its OpenAPI document.
